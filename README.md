# Swarm AI Algorithms

Coursework and lab exercises on swarm intelligence and optimization. This repository is a place for implementations, experiments, and notes as the labs progress.

## Topics

- Swarm intelligence and population-based search
- Benchmark functions for evaluating optimization algorithms
- Ant Colony Optimization (ACO)
- Particle Swarm Optimization (PSO)

## Getting started

1. Clone the repository:

   ```bash
   git clone https://github.com/Obaidullah32/swarmAI-algorithims.git
   cd swarmAI-algorithims
   ```

2. Open the lab folder or file you want to explore.
3. Use the environment appropriate for that exercise (for example, Python for `.py` files or Jupyter for `.ipynb` notebooks). Check the imports in each exercise for any packages it needs.

## What the experiments show

The exercises examine how a swarm searches for good solutions and how algorithm settings affect the result. Where an exercise uses a benchmark function, compare both the best objective value and the behavior across repeated runs.

## Repository status

This is an evolving collection of lab work. Individual exercises may use different inputs and settings; refer to the comments in each file for their specific steps.
